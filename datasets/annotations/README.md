# Annotations Directory
Menyimpan label anotasi bounding box (format YOLO `.txt`, Pascal VOC `.xml`, atau COCO `.json`) yang dibuat melalui labeling tool (misal: LabelImg, CVAT, Roboflow).
Catatan: Gambar mentah (*raw*) dipisahkan dari anotasi. Bounding box pretrained model tidak digunakan sebagai anotasi ground-truth.
